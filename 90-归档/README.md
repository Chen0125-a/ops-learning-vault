## 归档规则

1. 归档不是删除：原文件保留，可在需要时人工对照或恢复。
2. 只有未被 Markdown 链接引用、且不属于教学事实源的文件才能移入此处。
3. 技术知识的“简版/详解版”不是自动归档候选；若内容互补，应由对应 MOC 标明用途。
4. 不归档学习计划、学情档案、每日一问、错题本、教师包和正在使用的实验手册。
