# 通用协作记忆包：可迁移规则副本

使用此副本恢复新环境时，先把本记忆包和根目录 `AGENTS.md` 放入可被 Codex 读取的工作区。

处理用户任务时：

1. 先读取 `CURRENT.md`、`COLLABORATION_MEMORY.md` 和 `DECISIONS.md`。
2. 仅保存已经确认、具备证据且能在未来复用的协作事实、偏好、流程或决策。
3. 一次性观察写入 `MEMORY_INBOX.md`，复核后才提升为长期记忆。
4. 每个重要任务或关键决定结束后更新 `CURRENT.md`；不因普通闲聊而制造记忆。
5. 不写入密码、令牌、Cookie、API Key、私钥、认证文件、完整聊天记录、无关隐私或敏感终端输出。
6. 涉及运维实习学习时，以 `求职/运维实习-教师包/` 为课程事实源；本包不替代每日一问、错题本或教师交接。
