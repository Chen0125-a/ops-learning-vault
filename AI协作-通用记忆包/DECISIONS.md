# 长期协作决策

## D-001：采用“双记忆包”而非混合记录

- 日期：2026-07-25
- 状态：有效
- 决定：运维实习教学使用 `求职/运维实习-教师包/`；跨主题协作使用 `AI协作-通用记忆包/`。
- 原因：课程进度和个人通用协作规则的生命周期不同，混写会导致检索困难和上下文污染。
- 影响：课程细节不复制到通用包；通用偏好不替代课程教师包的事实来源。

## D-002：同步范围坚持最小必要原则

- 日期：2026-07-25
- 状态：有效
- 决定：通用协作记忆包纳入私有 GitHub 仓库 `ops-learning-vault` 的同步白名单。
- 原因：实现跨设备恢复，同时避免将整个 Obsidian 库、插件配置、认证数据或无关资料上传。
- 安全边界：严禁提交密码、令牌、Cookie、API Key、私钥、认证文件、完整聊天记录和敏感终端输出。

## D-003：当前三个月学习期间的技能边界

- 日期：2026-07-25
- 状态：有效
- 决定：三个月运维实习老师模式可以自动启用；长期学习教练和通用学习教练保持休眠，只有用户明确要求时才使用。
- 原因：当前阶段聚焦课程执行，避免多个学习工作流同时介入。
