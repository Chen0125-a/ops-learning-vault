# 通用协作记忆包

这是用户与 Codex 在课程之外共享的、可迁移的协作上下文。目标不是保存聊天记录，也不是复制模型本身，而是让新电脑、新账号或新的 Codex 能从可靠档案中接续协作。

## 这个包保存什么

| 层级 | 文件 | 内容 | 更新时机 |
|---|---|---|---|
| 即时交接 | `CURRENT.md` | 当前优先事项、正在执行的约定、下一步 | 每个重要任务或关键决定后 |
| 可复用经验 | `COLLABORATION_MEMORY.md` | 已验证的偏好、有效工作方式、环境事实 | 复核后才写入 |
| 长期决定 | `DECISIONS.md` | 用户确认的工具、资料、同步和安全选择 | 决定确认后 |
| 待验证观察 | `MEMORY_INBOX.md` | 一次性观察、候选经验、待确认事项 | 观察产生时 |
| 恢复指南 | `RESTORE.md` | 换电脑、换账号后的接班步骤 | 环境变化时 |
| 备份规范 | `BACKUP.md` | Git 同步范围、安全检查和灾备方式 | 备份方案变化时 |

## 与其他资料的关系

- **知识笔记与排错方案**：留在 Obsidian 的主题目录中；它们是用户的知识资产。
- **实验手册与帮助文档**：作为资料库保留，不等于已掌握的知识；实验结论应沉淀为自己的实验记录或解决方案。
- **运维实习教师包**：仅保存三个月运维教学所需的进度、学情、错题和教学经验。
- **本通用包**：只保存跨主题协作所需的稳定上下文，避免和课程内容重复。

## 准入与安全规则

1. 记录必须可复用、与未来协作有关，并有用户确认或明确证据。
2. 一次性印象、猜测和未经验证的偏好只能进入 `MEMORY_INBOX.md`。
3. 不保存密码、令牌、Cookie、API Key、私钥、认证文件、完整聊天记录或无关私人信息。
4. 新证据推翻旧结论时，不删除历史；标记“已废弃”并写明替代结论。
5. 本包不是“自动记录一切”的黑箱。每条长期记忆都应能解释来源、适用范围和状态。
