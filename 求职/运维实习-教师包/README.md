# 运维实习 · 可迁移教师记忆包

> 目标：让任何一台新电脑、任何一个新的 Codex 账号，都能从可验证的档案中接续教学，而不是依赖旧账号聊天记录或模型猜测。

## 记忆分层

| 层级 | 文件/位置 | 保存什么 | 更新条件 |
|---|---|---|---|
| 原始证据 | `../每日一问/`、`../../运维实习-错题本/` | 用户回答、命令、真实输出、重测结果 | 每个教学日结束 |
| 学情状态 | `../学情档案.md` | 学习画像、弱项、有效教法、进度快照 | 有新证据才更新 |
| 即时交接 | `CURRENT.md` | 当前 W/D、到期任务、下一步、已知阻塞 | 每次有效学习/项目决策后 |
| 可复用经验 | `TEACHING_MEMORY.md` | 证据支持的教学策略、批改铁律、协作经验 | 经过复核后提升 |
| 长期决策 | `DECISIONS.md` | 环境、安全、项目路线等持久选择及原因 | 用户确认或事实验证后 |
| 待验证观察 | `MEMORY_INBOX.md` | 一次观察或待复测的候选经验 | 产生时记录，验证后提升或废弃 |

## 准入原则

1. 不把聊天全文、模型主观印象或密码写进长期记忆。
2. 每条经验必须标明日期、来源、证据、适用范围和状态。
3. 一次偶发情况只进入 `MEMORY_INBOX.md`；重复出现或由用户明确确认后，才进入长期档案。
4. 真实终端输出、已归档实操和用户明确确认优先于理论推断。
5. 过期或被新证据推翻的条目不删除历史，应标为“已废弃”并写明替代结论。

## 每次教学结束后的固定收尾

1. 归档每日提问、实操和错题本。
2. 更新 `CURRENT.md` 的进度、到期重测和下一主题。
3. 从本次过程提炼至多 3 条候选经验，写入 `MEMORY_INBOX.md`。
4. 仅把已验证的候选经验提升到 `TEACHING_MEMORY.md` 或 `DECISIONS.md`。
5. 不记录密码、令牌、私钥、完整敏感终端输出或无关私密内容。

## 换机与换号

恢复方法见 [[RESTORE]]。`codex/` 已保存当前生效的 `AGENTS.md` 与 `yunwei-teacher` 技能源码；本目录、`学情档案.md`、学习计划、每日一问和错题本是迁移所需的核心资料。Codex 登录信息、令牌、缓存和旧聊天记录不是。
