# 长期决策记录

## D-001：学习记录以 Obsidian 笔记库为唯一事实库

- **状态**：生效｜**日期**：2026-07-25
- **决定**：学习计划、学情档案、每日一问、错题本和可迁移教师包都存放在 `D:\笔记`。
- **原因**：可离线阅读、可由不同 AI 共用、可复制到新电脑，不依赖单一 Codex 账号。
- **影响**：未来稳定经验应优先写入本笔记库；账户聊天只作临时上下文。

## D-002：每日训练采用双轨制

- **状态**：生效｜**日期**：2026-07-24
- **决定**：学习轨每天 2~2.5 小时；项目轨 4~4.5 小时；其余为弹性时间。
- **原因**：既练面试基本功，也形成可讲述的项目经历。

## D-003：实操以虚拟机和 RHEL 体系为准

- **状态**：生效｜**日期**：2026-07-23
- **决定**：优先 Rocky9/CentOS 体系，使用 `dnf`、`firewalld`、`/etc/sysconfig`；WSL2 仅作辅助，不替代完整 VM 实验。
- **约束**：宿主机 16G，VM 总预算约 9~10G；密码不落盘，破坏性操作前确认快照。

## D-004：LifeHub 是项目主线

- **状态**：生效｜**日期**：2026-07-24
- **决定**：用户负责部署与维护；AI 交付可部署的 Spring Boot 3 + Vue3 + MySQL 8 + Redis 应用及部署资料。
- **路线**：W5 手工部署 → W8 容器化 → W9 K8s → W10 监控 → W11 CI/CD。

## D-005：教师经验采用可迁移、证据分层的沉淀机制

- **状态**：生效｜**日期**：2026-07-25
- **决定**：以本教师包的 `CURRENT.md`、`TEACHING_MEMORY.md`、`DECISIONS.md` 和 `MEMORY_INBOX.md` 管理未来的交接、经验和待验证观察。
- **原因**：避免把长期能力依赖在单一电脑、单一账号或不可审计的聊天上下文中。
- **边界**：原始证据仍保留在每日一问和错题本；密码、令牌、私钥和未经验证的印象不得进入长期档案。

## D-006：教学资料原件保护与导航检索

- **状态**：生效｜**日期**：2026-07-25
- **决定**：学习计划、学情档案、每日一问、教师包和错题本保持原路径不动；开始教学时先从 `00-MOC-学习系统.md` 定位训练资料，再按主题 MOC 查阅技术笔记或资料库。
- **原因与证据**：知识库整理时确认实验手册和技术笔记已被计划、项目路线和教师资料交叉引用；批量移动会增加断链风险。
- **影响范围**：所有后续教学与知识库整理。
- **替代/回滚条件**：只有在完整链接清单、图片引用和教学检索验收均通过后，才可由用户明确授权调整原始目录。
