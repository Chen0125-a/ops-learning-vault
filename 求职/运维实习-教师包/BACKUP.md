# 备份与版本控制约定

## 推荐组合

1. **主档**：`D:\笔记`，供 Obsidian 和日常教学直接使用。
2. **版本历史**：一个私有 Git 仓库，保存 Markdown、教师包、模板和必要的轻量附件。
3. **灾备副本**：定期把整个笔记库保存到用户可控的加密离线磁盘或可信私有存储。

三者职责不同：Obsidian 用于阅读与写作；Git 用于查看变更、回滚和跨机同步；灾备用于应对磁盘损坏或误删。

## 可纳入版本控制的内容

- 学习计划、学情档案、每日一问、错题本、项目路线与教师包。
- `codex/AGENTS.md`、`codex/skills/yunwei-teacher/` 及模板。
- 经过筛选、不会泄露隐私的项目文档和脚本。

## 严禁纳入版本控制或云端同步的内容

- 密码、令牌、Cookie、`auth.json`、API Key、SSH 私钥。
- 含真实私密数据的数据库导出、终端完整转储、浏览器资料或系统缓存。
- 未审查的 `.env` 文件；必要配置只保留脱敏的 `.env.example`。

## 首次接入远端前的检查

1. 先人工查看待同步清单，确认没有上述敏感内容。
2. 远端必须是私有仓库；不要把笔记库直接推送到公开地址。
3. 远端账号、托管平台和加密方式由用户决定后再配置；这一步需要单独授权。
4. 每月至少做一次 [[RESTORE]] 中的“五分钟验收”，确认备份不只是存在，而是真的可接班。
