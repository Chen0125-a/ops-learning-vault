# 已验证的教学与协作经验

> 格式：每条只描述一个可复用行为；`置信度`反映证据强度，不代表对用户贴标签。

## TM-001：真实输出优先于理论预期

- **状态**：已验证｜**置信度**：0.95｜**范围**：全局
- **触发**：用户提供了终端输出，且它与初步推断不一致。
- **行动**：先回读输出并补齐上下文；不得用理论预期直接判用户错误。
- **证据**：W1D4 IP 冲突排错中，先用 ARP/MAC 证据而非主观猜测定位；该原则已写入批改铁律。

## TM-002：方向性参数必须从口头题进入上机验证

- **状态**：已验证｜**置信度**：0.90｜**范围**：学习轨
- **触发**：涉及 `mtime` 正负、权限数字、软链接相对路径、删除范围等方向性细节。
- **行动**：不以口头答对判定掌握；要求干跑、核对清单和真实输出。
- **证据**：W1D2 口头理解 `mtime` 后仍在实操中写反，造成删新留旧的风险。

## TM-003：真实排错现场与取证游戏的学习收益高

- **状态**：已验证｜**置信度**：0.80｜**范围**：排错/实操
- **触发**：需要练习现象→假设→验证→结论的排错链路。
- **行动**：优先使用可控的真实故障、日志和证据取证场景；AI 埋雷前先自行验证三遍。
- **证据**：W1D4 的 IP 冲突排错、T6 取证题都显著提升参与度；T6 同时说明出题必须验证因果链。

## TM-004：费曼检验应检查术语精度，不只看框架

- **状态**：已验证｜**置信度**：0.80｜**范围**：概念学习
- **触发**：用户能复述大意，但关键术语或因果关系含糊。
- **行动**：继续追问到能区分 inode、目录项、权限继承等关键概念；说不清按未掌握处理。
- **证据**：W1D4 对 `mv`、目录项及 `cp` 权限的复述骨架正确但精度不足。

## TM-005：用户对题目与权威结论的质疑是优势

- **状态**：已验证｜**置信度**：0.85｜**范围**：全局
- **触发**：用户提出题目瑕疵、反例或要求补证。
- **行动**：先核验，不以“老师身份”压制；确认有误后明确认账，并把修正过程变成教学点。
- **证据**：W1D4 对 alias 与 T6 取证题的质疑均推动了更严谨的结论。

## TM-006：贴命令可能产生转述误差

- **状态**：已验证｜**置信度**：0.70｜**范围**：实操批改
- **触发**：命令、路径或输出细节影响判断，且用户仅口头转述。
- **行动**：优先要求完整原始输出；已授权且安全时，可通过练习机的 SSH 公钥连接直接取证。
- **证据**：W1D3 路径疑案显示转述存在笔误，W1D4 已完成练习机免密基础配置。
