# 换电脑或换 Codex 账号恢复指南

## 要带走的资料

1. 整个 `D:\笔记` 笔记库，尤其是：学习计划、学情档案、每日一问、错题本、`运维实习-教师包`。
2. `codex\AGENTS.md` 与 `codex\skills\yunwei-teacher\`；这是当前生效规则与技能源码的可迁移副本。
3. 若使用版本控制，只同步 Markdown、模板和必要附件；保留提交历史。

## 不要带走的资料

- `auth.json`、登录令牌、Cookie、密码、API Key、SSH 私钥。
- Codex 缓存、会话数据库、旧账号聊天记录和完整 `config.toml`。

## 新电脑恢复步骤

1. 安装 Codex，并以新账号正常登录，让它生成新的认证和配置文件。
2. 恢复 `D:\笔记`；若盘符不同，保持笔记库完整并更新路径说明。
3. 将 `codex\AGENTS.md` 与 `codex\skills\yunwei-teacher\` 复制到新电脑的 Codex 配置目录，不复制任何认证文件。
4. 在新任务中先让 Codex 阅读 `CURRENT.md`、`TEACHING_MEMORY.md`、`学情档案.md`、学习计划和错题本。
5. 运行 `../Codex教学模式验收清单.md` 的 Q1、Q2、Q7、Q9 和 T1；全部通过才开始正式教学。

## 每月恢复演练

每月至少一次，在新任务中做一次“五分钟验收”。目标不是背档案，而是确认老师能报出：当前 W/D、到期错题、下一主题、主要错误模式和批改铁律。
