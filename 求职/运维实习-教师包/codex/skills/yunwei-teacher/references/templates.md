# 归档与错题本模板（与 Obsidian 现有格式严格一致）

权威模板以 `D:\笔记\求职\每日一问\_模板.md` 和错题本现有条目为准；本文件是快照，冲突时以 Obsidian 里的为准。

## 1. 每日一问归档模板

- 位置：`D:\笔记\求职\每日一问\`
- 命名：`YYYY-MM-DD_W{周}D{天}_主题.md`，例：`2026-07-21_W1D1_文件与权限.md`
- 归档后同步维护该目录 `README.md` 索引

```markdown
---
tags: [每日一问, 运维实习, W{周}]
date: {YYYY-MM-DD}
week: W{周}D{天}
---

# W{周}D{天} · {主题}

## 一、提问与批改

### Q1. {问题} [来源标签：JD高频/错题变体/排错场景/拓展]
- **我的回答**：
- **批改**：✅ / ⚠️ / ❌
- **解析**：

## 二、实操记录

### 实操 1：{题目}
- **要求**：
- **执行命令**：
```bash
# 贴实际执行的命令
```
- **真实输出**：
```
# 贴终端输出
```
- **验证结论**：✅ / ❌（错在哪 → 怎么改 → 生产后果）

## 三、当日错题

- [ ] {错题摘要} → 已沉淀至 [[运维实习-错题本]]
```

## 2. 错题本条目模板

- 位置：`D:\笔记\运维实习-错题本\`
- 命名：`W{周}D{天}_{知识点}.md`，例：`W1D2_mtime方向写反与干跑没核对.md`
- 第 3 天 = 当天日期 +2 天，第 7 天 = 当天日期 +6 天（与自然日间隔一致：如 7-22 的错题 retest 为 7-25、7-29）

```markdown
---
tags: [错题本, 运维实习, W{周}, {知识点标签}]
date: {YYYY-MM-DD}
source: W{周}D{天} {提问/实操} {题号}
retest: [第3天日期, 第7天日期]
status: 未清零
---

# 错题：{一句话概括，严重程度标注}

## 事故现场
{任务背景 + 用户实际执行 + 实际结果}

## 错误分析
{错在哪，逐条拆解}

## 生产后果
{这一步做错在生产环境导致什么}

## 正确姿势
{命令/做法 + 验证步骤}

## 变体重测记录
- [ ] {第3天日期}（第 3 天）：
- [ ] {第7天日期}（第 7 天）：

> 连续 2 次变体答对才清零；1 对 1 错 → 3 天后再测；全错 → 明天就重测（动态调整，回填时更新 retest）
```

## 3. 变体重测回填规则

- 变体答对/答错结果与日期填入"变体重测记录"对应复选框。
- 连对 2 次 → `status: 已清零`；否则更新 retest 为下次日期，保持 `status: 未清零`。
