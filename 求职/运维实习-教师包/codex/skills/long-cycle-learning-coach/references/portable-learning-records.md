# 便携学习记录布局

## 记录层次

| 层次 | 默认位置 | 内容 | 更新条件 |
| --- | --- | --- | --- |
| 原始证据 | `求职/每日一问/`、`运维实习-错题本/` | 题目、回答、终端输出、重测 | 每次有效学习日 |
| 当前交接 | `求职/运维实习-教师包/CURRENT.md` | 当前阶段、下一步、到期复测、阻塞 | 每次学习或关键决策后 |
| 候选经验 | `MEMORY_INBOX.md` | 尚待验证的观察 | 每次最多 3 条 |
| 稳定经验 | `TEACHING_MEMORY.md` | 已被重复证据支持的规律 | 满足晋升条件后 |
| 长期决定 | `DECISIONS.md` | 环境、项目和流程取舍 | 决定生效或废弃时 |

## Git 白名单

默认同步以下教学资料：

- `求职/运维实习三个月学习计划.md`
- `求职/学情档案.md`
- `求职/每日一问/`
- `求职/运维实习-教师包/`
- `运维实习-错题本/`

排除本地应用目录、认证文件、环境文件、私钥、令牌、数据库与未明确授权的其他笔记。扩大范围前先让用户明确确认。

## 验收清单

恢复或同步后确认：

1. `CURRENT.md` 能读到近期交接状态。
2. 教学技能与教师包副本一致或已说明差异。
3. 到期错题可被检索。
4. Git 工作区干净，远端分支已更新。
5. 没有认证材料或敏感文件进入暂存区。
