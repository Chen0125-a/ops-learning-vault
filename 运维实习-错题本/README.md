## 使用规则

1. 到期日期以每个条目的 `retest` frontmatter 为准。
2. 变体答对或答错后，回填“变体重测记录”；连续两次答对才清零。
3. 错题来源和完整实操证据回链到 [[求职/每日一问/README|每日一问]]。
4. 新错误只在具有真实练习证据、明确生产风险或概念性误解时入册。
